# Contributing

Thanks for your interest in CSV Cleaner.

This project is intentionally small and practical. Contributions that make CSV cleanup easier, safer, or better documented are welcome.

## Good First Contributions

- Add examples for common CSV cleaning tasks
- Improve Chinese or English documentation
- Add tests for edge cases
- Add preview mode
- Add batch processing for multiple CSV files
- Add date or number normalization

## Development

```bash
python -m unittest
```

## Pull Request Tips

- Keep changes focused
- Add or update tests when changing behavior
- Update README examples if user-facing behavior changes
- Avoid adding large dependencies unless they clearly improve the tool
